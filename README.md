# Автоточка

Android-приложение, которое само включает точку доступа, когда рядом появляется Bluetooth автомобиля. Сел в машину — телефон уже раздаёт интернет. Вышел — раздача выключилась.

Без root, без прошивок, без ручных действий.

## Зачем

Штатный Android не умеет включать точку доступа по событию. Приходится каждый раз лезть в настройки, а за рулём это неудобно и небезопасно. Приложение закрывает ровно эту дырку: подписался на имя Bluetooth-устройства машины — и дальше всё происходит само.

Триггером может быть любое Bluetooth-устройство: магнитола, наушники, часы, колонка.

## Как работает

1. Foreground-сервис раз в N секунд запускает поиск Bluetooth.
2. Увидел устройство с заданным именем или адресом — включает точку доступа.
3. Устройство не появлялось N минут — выключает её обратно.

Включение идёт через `TetheringManager.startTethering`. Этот интерфейс скрыт от обычных приложений, поэтому используются два приёма:

- **`WRITE_SETTINGS`** — разрешение «Изменение системных настроек». В модуле tethering проверка прав устроена так, что при наличии этого разрешения `startTethering` проходит.
- **Hidden API bypass** — библиотека [`org.lsposed.hiddenapibypass`](https://github.com/LSPosed/AndroidHiddenApiBypass), снимает запрет на обращение к скрытым методам через рефлексию.

Никакого root не требуется: оба приёма доступны обычному приложению.

## Требования

| Что | Значение |
|---|---|
| Android | 11–14 (в теории и выше, но поведение зависит от прошивки) |
| Разрешения | Bluetooth, уведомления, «Изменение системных настроек» |
| Root / Shizuku | не нужен |

**Важное ограничение.** Доступ к `TetheringManager` зависит от прошивки и версии модуля tethering. На части устройств автоматика не сработает — приложение честно покажет это в статусе. Проверяйте на своём телефоне: оно бесплатное.

## Сборка

Нужны:

- JDK 11+ (`javac`, `java`)
- Android build-tools: `aapt2`, `d8.jar`, `apksigner.jar`, `zipalign`
- `android-35.jar` (платформа Android 15) — скрипт подхватит её, если она есть в каталоге инструментов, иначе возьмёт `android-33.jar`

Сборка без Gradle — вызовом четырёх инструментов по очереди:

```powershell
powershell -ExecutionPolicy Bypass -File .\app\build-app.ps1 -Tools "C:\android-tools" -Install
```

`-Tools` — каталог, где лежат `aapt2.exe`, `android-33.jar`, `zipalign.exe` и подпапка `lib` с `d8.jar` и `apksigner.jar`. `-Install` дополнительно ставит APK на подключённый по adb телефон.

Ключ подписи создаётся один раз при первой сборке в `app/keys/` и переиспользуется. **Не публикуйте его в репозитории** — он в `.gitignore`.

## Структура

```
app/
  src/ru/baikalteam/autotochka/   исходники
    MainActivity.java             экран: статус, кнопки, настройки
    MonitorService.java           foreground-сервис, следит за Bluetooth
    Hotspot.java                  включение и выключение точки доступа
    BootReceiver.java             автозапуск после перезагрузки
    Prefs.java                    настройки
    Logs.java                     журнал событий
  res/                            иконки и разметка уведомления
  lib/                            HiddenApiBypass
  build-app.ps1                   сборка
landing/                          страница приложения
```

## Лендинг

`landing/` — статическая страница с описанием, требованиями и ссылкой на RuStore. Публикуется на `avtotochka.baikalteam.ru`.

## Приватность

Приложение не собирает персональные данные и не отправляет ничего на серверы. Имя Bluetooth-устройства и настройки хранятся локально. Подробнее — в [политике конфиденциальности](landing/privacy.html).
